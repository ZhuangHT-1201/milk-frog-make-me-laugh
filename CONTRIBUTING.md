# Contributing

Thanks for helping make the Milk Frog experiment worse in the best possible way.

## Development

1. Edit `src/game.html`.
2. Run `npm run build`.
3. Run `npm run check`.
4. Test the result with `npm start`.

No package installation is required.

## Contribution Guidelines

- Keep the game playable without a mouse.
- Test both desktop and mobile widths.
- Respect `prefers-reduced-motion`.
- Keep new humor absurd and harmless. Avoid attacks on real people or groups, gore, and dangerous instructions.
- New photo forms need a visible caption, an accessible label, and a distinct visual treatment.
- Do not add analytics, trackers, network APIs, or runtime dependencies without a clear reason.
- Keep saved data backward-compatible when possible.

## Pull Requests

Describe the new interaction, include a screenshot or short recording when visuals change, and list any new third-party assets with their licenses.
